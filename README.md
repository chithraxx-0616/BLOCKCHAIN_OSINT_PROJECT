\# 🦅 ChainHawk — Blockchain OSINT Tool



ChainHawk is a Python-based blockchain OSINT investigation tool designed to assist with cryptocurrency transaction analysis, wallet tracing, reputation checks, multi-hop investigations, and transaction visualization.



\## Features



\- 🔎 Bitcoin and Ethereum wallet investigation

\- 🔗 Multi-hop transaction tracing

\- 📊 Interactive transaction/network visualization

\- ➡️ Directional transaction flow analysis

\- 🧾 Transaction intelligence and investigation details

\- 🚨 Transaction monitoring and alert severity

\- 📅 Transaction timeline analysis

\- 📁 Investigation reports and evidence/provenance

\- ⚙️ API configuration and connectivity testing

\- 🗂️ Case management

\- 🧪 Clearly labelled simulation/demo mode

\- 🦅 ChainHawk investigation interface



\## Technologies



\- Python

\- Tkinter

\- NetworkX

\- Matplotlib

\- SQLite

\- REST APIs

\- Bitcoin / Ethereum blockchain data



\## Security



API credentials should be supplied through environment variables.



Do \*\*not\*\* commit API keys, `.env` files, databases, or other sensitive credentials to this repository.
